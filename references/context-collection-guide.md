# 渐进式上下文收集指南

> 来源: agent-dev-kit 上下文收集基线

## 4 步骤流程

### Step 1: 结构化扫描
快速浏览项目目录结构、AGENTS.md、README、关键配置文件。

### Step 2: 识别疑问
列出不确定的点（架构决策、接口约定、隐式依赖等）。

### Step 3: 针对性深挖
逐个解答疑问，最多深挖 **3 次**，第 3 次提醒评估成本。

### Step 4: 充分性检查
以下 4 项全部打勾方可开始执行：
- [ ] 接口契约已明确
- [ ] 技术选型理由已记录
- [ ] 风险点已识别
- [ ] 验证方式已确定

## 成本控制
- 深挖 ≤ 3 次
- 第 3 次时提醒：继续深挖的成本是否值得？
- 如果仍不确定，先用最小方案验证
