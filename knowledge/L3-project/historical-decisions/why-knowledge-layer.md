# 为什么引入知识分层架构

> 日期: 2026-05-12
> 决策者: leiwenjun

## 背景

随着 adk 的发展，文档和知识越来越多，但缺乏有效的组织和管理。

## 问题

1. **知识散落**: 文档分散在各个目录，难以查找
2. **缺乏分层**: 所有知识平铺，没有层次结构
3. **缺乏分类**: 没有明确的知识类型定义
4. **缺乏成熟度**: 没有知识质量评估机制

## 解决方案

引入五层知识存储架构：

- Layer 0: 工具链配置知识
- Layer 1: 通用技术知识
- Layer 2: 业务领域知识
- Layer 3: 项目上下文
- Layer 4: 会话上下文

## 收益

1. **精准组织**: 知识按层级和类型组织
2. **按需消费**: Agent 可以精准获取所需知识
3. **质量可控**: 知识有成熟度评估
4. **易于维护**: 知识边界清晰
