# ADR-001: 8 阶段生命周期框架

> 状态: accepted
> 日期: 2026-05-12
> 决策者: leiwenjun

## 背景

需要一个结构化的生命周期框架来组织 AI 驱动的软件交付流程。

## 决策

采用 VibeFlow 的 8 阶段生命周期框架：

```
Spark → Design → Tasks → Build → Review → Test → Ship → Reflect
```

## 原因

1. **完整性**: 覆盖从需求到复盘的完整流程
2. **可恢复**: 支持中断恢复和跨会话交接
3. **可门禁**: 每个阶段有明确的门禁检查
4. **可沉淀**: 每个阶段自动沉淀知识

## 后果

### 正面

- 流程清晰，易于理解和执行
- 支持中断恢复，提高容错性
- 门禁机制保证质量
- 知识自动沉淀

### 负面

- 流程较长，小型变更可能过度
- 需要维护状态文件
- 增加了学习成本
