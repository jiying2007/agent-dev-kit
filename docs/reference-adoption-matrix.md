## 使用说明

1. 每个候选项对应一行，不跨行合并多个能力点。
2. `决策` 仅允许：`adopt`、`observe`、`reject`。
3. `验收状态` 仅允许：`done`、`pending`、`blocked`。
4. `证据` 必须包含可复现命令或报告路径。
5. `回灌目标` 默认填写 `agent-dev-kit`，如需试跑可追加 `codex`。
