# Design, change boundaries and rollback

The only interactive discovery route remains the existing ADK Skill; no Superpowers/Grill Me branded duplicates. Negation uses a bounded same-clause filler grammar, including English 'do not', while unrelated positive requests remain active. Standalone AAR ships its three template dependencies as reference files with parity tests; repository-only governance commands become conditional. Side-effect classifications distinguish passive observation, active bus probes, target pauses and destructive writes. Exported provenance becomes a namespaced string mapping.

Only registered Skill contents change; runtime installation is not implied. Release follows protected CI and exact SHA/immutable tag semantics. Revert via reviewed PR, never move an immutable tag. No runtime/field qualification is fabricated.
