# 当前意图与当前内容的一致执行

## 目标与授权

基线为 ADK `6d902f721f560f02883516e809fbd93a326405b6`（11.3.14）。
用户要求“全面审查adk，全网搜索，全面优化”；已有同项目公开推送、受保护合并、
组件发布与 source-only Root 接入授权继续有效。独立自动审查沿用现有
`.adk/review-policy.json`，不新增授权或门禁。

审查全部 65 个 Skill 及其直接参考、typed core 的选择/缓存/评测/交付边界；
只改变有原始来源或实际反例支持的行为。目标是使选择结果服从当前请求、
执行语义对应当前内容，并在压缩后恢复实际需要的 Skill 指导。

## 非目标

不增加 Skill 身份、生产 runtime、后台巡检、模型调用或依赖。不放宽既有
Profile 源字节预算、固定评测输入/期望值、权限、独立审查或发布检查。
不把源码/本地 CLI/host 测试视为模型效果、Token/费用、native 加载或设备资格。
ADC/CMake 历史超时仅在有可复现根因时修复，否则保留真实未解状态。

## 验收

1. 文件内容或 schema 同长度变化且 mtime 不变时，缓存必须重新解析/校验；
   phase/relationship 报告的摘要与实际解析的同一份字节一致。缓存仍有界，
   不变输入可复用昂贵解析。缺失/无效输入保持明确失败。
2. 中英文明确禁止创建 worktree 不得通过较短触发词重新选中该写操作；
   同句其他肯定动作不受无关否定影响。
3. 明确编写/更新 ADR 的动作不被接口等主题夺走；概念解释、接口实现、
   否定 ADR 的相邻反例不误选文档写作。自然 RTOS SPI/DMA 驱动实现请求
   可选择已有实现能力；解释/只读/域外/否定条件保持原权限边界。
4. 现有 context/handoff 方法区分完整正文仍在、正文已丢失或被摘要、来源变化。
   只恢复当前仍需的 Skill/参考；历史“已加载”不替代当前有效内容或增加权限。
5. 65 项审查有逐项结论；全部 8 个原 Profile ratchet 通过；固定路由评测、
   新增失败回归、完整现有测试和独立 Spec/Quality 审查通过。
6. 版本推进到 11.3.15；源码、PR/main CI、不可变发布与实际 Root 消费各自核实。
   无法执行项如实记录原因，不把启动/已排队称为完成。
7. 效果 campaign 的安全判断只接受布尔值；耗时/费用只接受有限、合法数值，
   拒绝 bool 作为整数、NaN 和 infinity。原运行错误可表示缺失成本的语义保持；
   坏输入不得成为真实安全/耗时/零费用观测。
