# 方案与风险

冻结原完整目标与验收分母；阶段只选择有限纵向交付。进度记录关联原success criterion、已登记证据及变化类别；重复digest不产生新的有效进度。保留旧revision-only事件的历史可读取性，明确其不能持续清除停滞。阶段采用独立milestone gate，复用预算/停滞判定但不要求整个目标完成，也不授予commit/apply/release。

重规划通过结构化前后计划hash与调整维度证明实际调整；单纯提预算不算重规划进度。预算报告独立于证据终态，维持原final语义并明确预算状态，真实执行仍消费steady判断。

工件采用一份当前状态，保存下一步及证据指针；不新增平行工作流。根因明确时允许直接因果链，风险高时继续负向/回滚和独立审查。确定性测试覆盖正例、空增、重复证据、过期阶段、预算超限与旧事件回放。

风险：扩展事件/decision输出须同步schema与调用方；旧线程继续使用旧命令时需明确未验证进度，不能重写journal。Codex现有dirty属于用户，合并适配最小化。同步必须经真实受管来源与source-to-live门禁；无法满足时交付源码与具体阻塞。
