# Goal 工作流收敛优化

status: in_progress

目标：落实本次工作流诊断的六项建议：有效进度、阶段收口、有效重规划、状态去重、按风险选择方法、预算与证据分开报告。

边界：ADK typed core、技能与现有 runbook、确定性测试；Codex host adapter 只作必要适配，第三方来源必须 exact 导入，不手改镜像。GROS 仅调整阶段调度，保留原完整验收，不修改其源码或代替正在运行的线程登记状态。不自动提交、推送或发布。

验收：revision 空增不能持续清除停滞；新证据/关键假设/阻塞变化能推进且关联原验收；阶段收口不 complete 整体或绕过最终门禁；重规划必须携带前后计划身份及实际调整；当前状态单一入口并有体量检查；简单明确根因无需凑5Why或证伪；final 单列预算状态，不把证据PASS当预算合规。

停止条件：完成已授权源码实施、适用测试及审查；受管导入缺真实commit/签名则单列同步阻塞并准备明确后续，不伪造来源或扩大提交权限。
