# Skill 默认装载精简：需求

- 背景：默认 core 装载 22 个 Skill，其中 4 个只在 Goal 合同、并行开发、工作树隔离或跨会话恢复时使用；专业 Profile 已能表达这些工作。
- 目标：默认 core 降至 18，保持现有 65 个能力及其他 Profile 的完整集合不变；不更改工具权限、安装 API 或用户已部署目录。
- 验收：Profile 解析集合对照、路由正反例、安装和完整 CI 通过；文档只描述源码变化，不假定模型耗时与 Token 收益。
- 非目标：删除嵌入式专业 Skills、新建 Profile/路由引擎、引入兼容别名或自动安装用户环境。
