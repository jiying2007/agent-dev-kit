# Delegated review delivery checklist

- [x] Canonical Change Contract 追溯关系完整
- [x] Skill Intake 归属与安装范围结论
- [x] Prompt before/after 对比证据
- [ ] Evidence Index 命令级字段完整（命令/退出码/结果摘要/证据路径/层级/关联工件）
- [ ] 关键场景覆盖
- [ ] 风险项评估完成
- [ ] 回退方案可执行
- [ ] 验证证据可追溯
- [ ] 评审结果为 pass（无 blocker/major 未闭环）
- [ ] 收敛结论或阻塞说明
