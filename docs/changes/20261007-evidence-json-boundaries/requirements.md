# 证据 JSON 边界一致性

目标：目标契约、归档 manifest 和晋级证据必须拒绝歧义及资源超限 JSON；晋级输出不能跟随叶节点链接写到目录外。

范围：typed core 的三个读取模块、晋级输出及确定性测试。保留现有 schema、摘要算法与有效 JSON 内容；本轮不改变模型、权限、profile 或 release qualification。

验收：重复键（含嵌套/转义）、非有限数值、深度/大小超限、无效 UTF-8、非对象、符号链接/FIFO 被拒绝；有效原始来源身份不变，晋级有效输出可复读，已有文件在生成失败时不改变。定向测试、适用全量回归与独立整批复审形成新鲜证据。

风险：严格读取可能拒绝历史歧义输入，调用者应修复原始证据，不能静默标准化。POSIX 安全描述符读取不可用的平台保持 fail-closed；不承诺抵御父目录/同 UID 并发攻击。
