# 设计：统一路径身份与输出集合

设计者：主 Agent。实现由独立 implement_paths 承担；审核由不同身份只读完成。

## 所有权与边界

- compiler 保留原始 output root/target 表达，在 resolve 前检查路径；复用 installation_contract 的既有普通路径策略，不新增平行安全模块。
- 获取现有 TargetLock 后复核；替换前再次验证，保留已有 backup/recovery 协议。
- Native 输出集合预检在命令入口执行，使用规范化路径和已有文件身份拒绝 alias；输入路径不得成为输出目标。
- 单文件和批量写入统一由现有 atomic_io owner 承担。批量入口先序列化/stage，再顺序发布并在失败时补偿恢复；无法恢复时保留备份位置。
- 所有异常均明确失败；不能用第二次写入覆盖第一输出作为成功。

## 接口、迁移与回滚

既有合法 CLI 形状保持，原先接受的 symlink/FIFO/冲突路径改为拒绝。检索所有调用点和测试替身后修改内部接口。回滚通过受保护变更恢复既有实现；回滚不清理用户输出。共享版本与发布整合由主 Agent 串行处理。

## 方法吸收

吸收本轮外部研究中的明确模块职责、真实行为负例及幂等恢复方法；不复制第三方代码或引入依赖。
