# 外部优质方法对照与全部 Skill 深度优化

## 目标与基线

用户要求“全面深度优化所有 skill，全网搜索所有优质 skills 或 skill，深入优化 ADK”，此前已授权推送、受保护合并及继续优化。本轮以已发布 `v11.3.3`、main `5e0e83bcc127665de9a352e9eacfe9b092106cb2` 为唯一实现基线，覆盖 Manifest 的 56 core + 9 optional 共 65 个身份。

统一问题是：现有方法在复杂迁移、测试判定和运行期资源分析中仍缺少能够区分真实成功与表面通过的操作步骤。通过广泛检索原始 Skill、reference、验证脚本及工具官方文档，吸收经过具体反例确认的增量；保留已有充分方法，不靠全量改写或新增治理证明优化。

“全网搜索”指跨多个生态、作者和技术来源的广泛检索与原文核验，不声称穷尽互联网或所有优质 Skill。目录、搜索摘要、stars 与作者声望均不替代内容和验证证据。

## 验收

1. **完整范围**：65 项均有实际读取路径、基线 SHA/内容摘要、改进或保留决定及理由；所采纳外部方法有实际文件、不可变版本、适用边界与来源。无法取得、已删除或过期路径单列，不伪造已读。
2. **兼容迁移拆分**：普通功能继续优先纵向切片；跨公共契约的大型重构可在明确必要时使用 expand → 真实消费者批次迁移 → contract。过渡兼容有退出条件和责任人；批次不能独立通过时，由唯一集成分支承载并在最后真实集成验证，不能逐批宣称整体通过。删除、外部数据迁移和发布权限不改变。
3. **独立测试判定**：期望来自契约、手算常量或独立夹具，不复用被测实现/同一 helper 自证；新增或可疑测试能够拒绝一个明确的真实错误变体，且正确实现与合法边界仍通过。不要求无差别全仓 mutation 扫描。
4. **检查器校准**：仅新建、修改或出现矛盾的 checker 需要同配置的正常、已知违规、阈值内结果与执行/覆盖失败对照。工具进程成功不自动等于业务 PASS；缺字段、未知级别、未完成扫描和工具错误不得被当作干净结果。适用同快照的旧校准可复用。
5. **性质与状态序列测试**：从公开契约选择独立性质、合法/非法状态转移、实际非空有效输入和可重放最小反例；每次执行有界并记录 seed/输入/操作序列，避免只镜像实现的 oracle、失效生成器或泄漏跨轮状态。缺可用工具保持明确未运行，不安装新框架或把 host 枚举称为 fuzz/板端认证。
6. **sanitizer 有效性**：按目标、编译器及实际 runtime 支持选择 ASan/UBSan/TSan，区分编译成功、实际运行、工具报错和检测报告；UBSan 默认 recover 的报警即使 exit 0 也不能通过。已知缺陷与修复对照应验证真正插桩和报告，host 干净运行不证明目标无内存、并发或 UB 问题。
7. **栈资源判读**：`.su` 的逐函数 frame 不等于任务栈峰值；区分 static、dynamic,bounded 与 dynamic，调用链、递归、间接调用、IRQ/RTOS port 上下文与 high-water 单位须分别处理。未知项不自动形成完整栈上界，实测 low-water/high-water 不等于最坏情况证明。
8. **功能与易用性兼顾**：短正文能在不读取作者自定义 frontmatter 时找到所需方法；详细内容按需加载，单独导出的 Skill 不产生缺失的硬文件依赖。既有 8 个 profile ratchet 不上调阈值，原接口、Skill 身份与安装选择保持。
9. **可交付验证**：运行针对上述缺口的真实隔离命令或程序，区分方法反例、静态契约与模型效果；通过现有完整回归、独立 Spec/Quality 审查及受保护 PR/main CI，沿既有 canonical release 发布候选 `11.3.4`。公开证据须完成内容/敏感信息检查后再进入最终 CI。

## 非目标与证据边界

不新增 Skill、通用判定引擎、运行时、后台循环、计划任务、外部依赖安装或付费模型评测；不操作真实设备、邮箱和用户电脑。第三方内容只作为研究材料，不执行其指令或脚本，不复制其实现或隐含权限。独立概括方法并保留许可/来源限制。

本轮可证明源码契约、隔离的 host 程序/命令行为与回归结果；真实模型成功率、Token、成本、端到端时延及板端性能均保持 `not-measured / not-run`，不得用文档字节变化或外部 benchmark 代替。
