# 真实运行时评测可比性

## 目标

`eval compare` 只比较同一有序任务集、相同 grader 合同和相同请求模型/CLI 版本的 baseline 与 ADK 报告，并披露逐例退化。现有仅核 ID 顺序会让不同提示词或标签被误作同一实验。

## 验收

1. 新生成的 runtime 报告在执行前冻结任务集，并绑定摘要、逐例 prompt 摘要、grader 合同、manifest 身份和真实运行时版本；不保存原始 prompt 于报告。
2. 比较前拒绝旧版缺身份、任务摘要/逐例提示词或标签不一致、grader 合同不一致、模型/运行时版本不一致的报告。
3. 平均指标改善但至少一个原本通过的用例退化时，比较结果不得为 `pass`；列出退化和改善 ID。
4. 输入身份字段来自报告本身，未被外部签名或可信执行器认证；比较 `pass` 不授予发布权限。
5. Python 3.8 可运行，现有计划模式与历史报告归档仍可读；旧报告须重新实测后才能进入新的比较门禁。

本批只改本地 ADK 源码和确定性测试，不执行真实模型调用、外部写入或 live apply。
