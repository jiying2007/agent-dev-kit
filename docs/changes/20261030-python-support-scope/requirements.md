# 区分 Python 兼容与验证范围

## 目标

将最低可运行版本、项目 CI 验证矩阵及解释器上游维护状态分别表达，消除 supported 单一名称的歧义。

Owner 已在 2026-10-30 审查后授权按建议全部优化落地。

## 边界

保持 Python >=3.8 包兼容下限和现有 launcher 选择顺序；不静默增加发布权限，不移除旧宿主兼容。

## 验收

1. 3.8/3.9/3.10 明确为上游 EOL；3.11/3.12 明确为当前项目验证范围。
2. 3.7 仍拒绝；新解释器不被自动宣称已经过项目 CI 验证。
3. doctor 与 launcher、README 的口径一致，测试不启动真实模型或 runtime。
