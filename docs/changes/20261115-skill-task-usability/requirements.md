# 全部 Skills 的任务效果与易用性

用户要求覆盖全部 65 个现有 Skill 的功能、质量、性能、易用性，不能继续只优化治理。基线为 `c57f4f8a7983f52257c0587eb85881a006e6dc07` / 11.3.1；沿用现有授权推进、独立审核和受保护 PR，不新增 Skill、运行时、巡检或付费模型任务，不操作用户本地电脑。

## 验收

1. 全部登记职责纳入任务检查；已有充分方法保留，发现的具体执行缺陷在原 Skill 修复，不能以批量加模板冒充改进。
2. 用户从实际任务找到入口、提供最少必要输入并知道可用输出；修复失效命令和把工具适用性误当通用条件的示例。
3. Goal 只读恢复保留阻塞、证据、在途工作与历史指针；已关闭或被阻塞的历史批次可以恢复查看，严格的待执行批次校验和父目标完成权限保持独立。
4. 嵌入式兼容、性能、测试、调试等流程依据目标类型给出可执行的方法；结果不能吞掉退出码或夸大证据范围。
5. 定向回归、现有全部必需检查和独立 Spec/Quality 审核通过后才合并；真实模型任务收益仍需独立实测，不以文字检查宣称成功率、Token 或时延收益。

## 非目标

不升级用户真实运行时，不取消或绕过现有设备/发布权限，不更换原始 65 项身份，不复制外部 Skill，不增加评测平台。源码/CLI 修复与模型行为效果分别报告。
