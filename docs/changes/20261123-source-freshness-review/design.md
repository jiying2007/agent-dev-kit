# 续审规则

官方记录依据逐条复核更新。完整且近期稳定的材料采用 90 天窗口。宿主功能配置、正在迁移的文档及退役能力分别使用 60、45 或 30 天窗口。生态来源通常为 30 天，固定版本的论文方法为 60 天。

退役的 Codex MCP server 来源保留稳定 ID 和现行官方撤除说明，降为观察，通用 runner 采用本地合约。新远程运行能力须独立确认。OpenAI 模型、插件安全和自定义 MCP 来源的新版链接按实际内容收敛采纳范围。

外部参考使用只读网页或固定 Git revision。保留原许可和仅方法/观察约束。不导入代码、文档原文、运行设置或新工具授权。
