# 外部 Skills 方法吸收 — 需求
- 默认只读 `method-only`，提供冻结的来源身份、license、ADK 等价能力、可证伪净增益和不适用边界。
- 只有可执行代码/高权限/供应链风险或用户要求时触发 `deep-audit`，禁止执行不可信脚本。
- 不能隐式修改外部仓、ADK adoption matrix、长期记忆、配置或触发付费模型。
- 与现有 optional Skill 组合治理及行为评测规范配合，不新建控制层/Skill/Agent/Workflow。
- 源码断言 + 12 个预期/禁止场景仅是 source-only，真实行为与 Token/时延为 `not-measured`。
