# 需求 — Skills 方法质量修复

基线 ADK 11.1.0，目标为已存在 Skill 方法深度提升、修复不闭合 Markdown 围栏，以及可复跑但不伪造的行为评测。

接受条件：64 个登记 Skill 入口围栏闭合；深模块设计考虑调用者/公开 seam/选项；困难 bug 建最短反馈信号；TDD 红灯必须由目标行为失败导致；复杂计划以可运行纵向切片和真实文件/验证命令为单位；研究原型区分只读设计与实际写入权限；Skill 变更先建立失败基线，缺真实模型测试时记 not-measured。

非目标：创建新 Skill/Agent/Workflow、安装上游 runtime、突破设备/发布权限、消耗共享 Codex/Work 额度、以静态通过宣称行为效果已提升。
