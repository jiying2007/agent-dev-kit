# Skills 真实任务执行证据

## 目标与授权

用户于 2026-11-14 要求按照《ADK Skills 实效迭代方案 2026年11月14日》完成迭代。方案：
https://chatgpt.com/space/page_b7138a96c4588191afaa4df2ebb7bd5f 。
本变更实现既有证据链的真实任务导入、代表任务与已有 Skills 的执行行为补齐；
用户授权实施与受保护 PR 推进，不扩大运行时、外部凭据或产品资格权限。

## 验收标准

- R1：一个非执行、只读输入的 CLI 可将明确版本的任务观测包导入现有 Run Evidence；
  绑定原始轨迹、输入/初始状态、实际 Skill 暴露与验收结果，复用 compare-trials。
  任务配对入口必须逐份核对这些实际绑定与冻结计划；同输入而初始工作区不同不得通过。
  单份导入不能独自证明受控配对；输入或输出路径不得破坏已读取的观测与引用材料。
- R2：任务成功必须来自独立验收材料与产物身份，不能来自路由匹配或模型自称完成；
  成功、失败、阻塞和缺测保持真实语义，过程 guardrail 独立于结果。
- R3：使用现有 Token/费用/工具/人工干预字段；未知计数拒绝完整导入，缺用量显式 unavailable。
  覆盖失败、重试、子任务；不得以字符数冒充 Token 或把费用估计称为账单。
- R4：输入路径有界、拒绝逃逸/符号链接/摘要不符/重复记录/无效JSON，
  不执行观测包内命令、不访问网络、不加载任意 Python、不读未声明文件。
- R5：真实任务证据与开发 fixture 分离。合成测试只能证明导入和验收机制；
  不伪造 E2-E4、真实模型增益、安装、发布或生产资格。
  固定任务预算超时及预期使用 Skill 却未触发的情况保留为有效失败/错误路由；
  不因候选表现差而选择性剔除。对照污染与环境漂移另记 invalid，并保留原因。
- R6：沿用已有 65 个 Skill 身份；完善 Goal恢复、单假设调试、局部 Review、
  文档读者验收、领域适用性与外部方法按失败吸收。已有内容直接复用，不复制规则。
- R7：提供代表 8 类任务的开发基准及外部验收入口/说明；旧作者曝光案例不升级为独立 holdout。
  基准不得启动付费模型、Codex/Work、计划任务或第三方安装。
- R8：定向负例、完整回归与独立 Spec/Quality 审查通过后走受保护合并；
  真正无法获得的运行时观测明确 evidence-blocked，并保留可执行恢复入口。

## 范围外

不修改现有路由 materializer 的意义，不新建生产 agent runtime、scheduler 或统计引擎；
不自动安装技能、改变安全/发布政策、调用 Codex/ChatGPT Work 额度或创建定时巡检。
