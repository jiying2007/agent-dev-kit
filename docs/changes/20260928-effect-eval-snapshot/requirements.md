# 静态 effect 评测输入快照

## 目标

`eval effect` 的输入、标签摘要必须绑定实际解析并评分的字节。当前先计算文件 hash、后从路径再次读取，文件变化时可能使报告摘要与评分输入分离。

## 验收

1. 输入与标签各读取一次，对同一已读取字节做大小、UTF-8/JSON、契约摘要和评分解析。
2. 输入限 1 MiB，标签限 256 KiB；拒绝符号链接和超预算文件。
3. 即使读取后路径内容变化，已完成的评分和报告摘要也只对应捕获的字节；跨两个文件及 manifest 的原子快照仍不宣称成立。
4. 既有 24 例 OOD/对抗测试与无原始 prompt 输出语义保持可用，Python 3.8 定向负例通过。

仅修改本地源码与测试，不执行真实模型或外部写入。
