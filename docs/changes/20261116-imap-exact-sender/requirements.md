# IMAP 完整发件地址判定

## 目标

补齐现有optional IMAP Skill在明确完整发件地址请求下的最终筛选。RFC9051的FROM搜索为子串候选，显示名伪装和相似域名不能冒充完整邮箱相等。该问题已有上一轮审计观察，但未实施。

## 边界与验收

普通模糊发件人请求保留原语义；只有明确完整地址条件才解析From并按明确邮箱语义筛选。不得擅自将local-part转小写、折叠别名或视为身份认证。候选需有覆盖依据；缺失/畸形/语义不明或预算不足保留成功项和未判定UID，partial，不扩大邮箱或下载无关正文。

验证真实标准库解析下：裸地址、显示名+正确地址通过；显示名中伪装目标和后缀域名排除；域名大小写与local-part/别名条件按明确语义处理；缺失/畸形头、数量/字节预算及模糊模式保持可解释结果。保留EXAMINE/BODY.PEEK/UIDVALIDITY与凭证限制。
