# Review feedback triage requirements

- Single finding feedback: bounded read-only source/evidence verification, no full review/CI by default.
- Never emit a final pass, readiness, SCM comment or mutation from feedback triage.
- Escalate cross-file, lifecycle, shared state, permission, security or unknown impact to whole review; evidence absence stays unverified.
- Preserve final whole-diff/whole-lifecycle, independence, snapshot, design-change, blocker and trusted-trigger safety gates.
- Six source-only cases; actual model quality, Token and latency are `not-measured`. No new Skill/Agent/Workflow or paid Codex/Work run.
