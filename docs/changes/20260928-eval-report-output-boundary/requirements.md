# 评测 Markdown 输出边界

## 目标

`eval report` 接受 JSON 报告并生成 Markdown。任务 ID、分类和结果字段可能来自外部任务集或运行时，不能通过换行、表格分隔符、HTML 或 Markdown 链接改变报告结构。

## 验收

1. 所有动态表格单元格及关键摘要值按纯文本渲染；控制字符和多行输入折叠为空格。
2. 竖线、反斜杠、Markdown 强调/链接字符被转义，HTML 标签被实体化。
3. 正常评测报告仍保留任务、评分和来源摘要；对抗样本不能插入伪造行或伪造完成字段。
4. 渲染防护不认证输入报告、grader、模型结果或完成权限。
5. 非对象报告、非对象列表结果和非对象 latency 明确拒绝，不输出半成品 Markdown。

仅改本地 Markdown 呈现，不调用外部写入或运行时。
