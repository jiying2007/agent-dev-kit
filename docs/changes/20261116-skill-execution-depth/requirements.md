# 全量 Skills 执行深度与可用性

## 目标

在已发布 `11.3.7` / `5f442723e95fa7ca846b7c3ddc9f9995c7a27065` 上继续全面检查 56 core 与 9 optional Skills，吸收一手外部实现中可验证的有效方法，修复实际任务中的功能、正确性、性能或使用障碍。用户已授权公开推送、独立自动审核、受保护合并及既有发布流程。

## 边界

- 沿用现有 Skill 身份、目标运行时、权限、原始验收和 profile 容量约束；不安装外部 Skill pack，不引入新执行框架。
- 保留有效方法，只修改有原始依据或隔离反例的缺口；全量审查不要求全量改写。
- 不启动外部付费模型、Codex/ChatGPT Work CLI/Cloud 任务、巡检或设备操作。真实模型 A/B、Token、成本、板端与 HIL 效果没有实测就不作声明。
- 复用上一轮已完成发布与验证，不修改历史记录和不可变标签。

## 验收

1. 65 个入口及其配套资源均有当前基线读取记录和逐项处理理由；来源研究包含具体文件、版本/摘要、许可及采用/保留理由。
2. 每个行为修复有独立于实现的观察条件；适合执行的命令以真实工具在隔离目录验证成功与失败路径，保留原始失败。
3. 全部原 profile 容量上限与现有质量门禁保持；共享逻辑、版本或打包变更运行完整回归。
4. 冻结源码经独立只读 Spec/Quality 审核；最终 PR 的受保护检查、合并主线及正式 Release 分别实查后报告。
5. 发布偶发 CTest 超时仅在根因证据充分时修复；否则保持未知，不扩大预算、删除测试或以重复绿色证明根因消失。
