# Git 二分测试日志兼容：任务

- T1 固定失败：核对原 CI job、Git 版本、三项失败及 101/102 汇总；保留原日志与实际 RED。
- T2 修复测试适配：集中两种真实格式并覆盖唯一/歧义/错误退出正反例，保留所有已发布 shell 的真实 Git 历史断言；verify 为定向模块及 Skill 内容入口。
- T3 冻结并独立审查：绑定准确 source/tree/patch、逐文件 SHA256 和原方法文件未变身份；独立 Spec/Quality 裁决不得冒充新来源全量 CI。
- T4 平台交付：同 PR 更新准确 head，既有完整 CI 必须通过，再按原授权受保护合并、发布和 Root source-only 接入。结果按实际发生时间追加验证记录与 PR。

实现者负责测试模块和父变更的 CI follow-up 说明；主整合者负责本合同与证据包装；独立审核者不改实现。原方法级源码审查及其当时回归保持历史身份。
