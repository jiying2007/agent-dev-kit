# Git 二分测试日志兼容：需求

## 已观察问题

ADK PR #275 的 CI run `43812320483` / job `133116507717` 在 Git 2.56.1 上实际运行 102 组测试，101 组通过。新增 Git 方法测试中的两项唯一裁决已经得到正确提交，但只识别 `# first bad commit:` 的测试解析器未识别 `# first 'bad' commit:`；另一项歧义断言未识别 `The first 'bad' commit could be any of:`。本地 Git 2.52.0 使用无引号形式。原始失败是测试兼容性缺口，不是可无改动重跑的偶发成功判据。

## 目标与验收

- 支持两种实际观察到的终局与歧义日志形态。
- 唯一裁决仍必须要求成功退出、准确 SHA 和恰好一个终局；缺失、重复、畸形、歧义或执行失败均不得通过。
- 保留已发布 shell 的真实 Git 历史案例、unknown/error 中止，以及 skipped boundary 不得伪造唯一裁决的检查。
- 新旧形态的确定性正反例、完整 Git 方法测试和既有 Skill 内容入口通过；新 PR head 必须完成既有完整 CI。
- 原方法源码、CI、阈值、版本与旧失败证据保持各自身份，不把历史本地 102/102 转记为新来源结果。

## 非目标

不新增生产日志解析器或 Git 依赖，不修改 Skill 方法、运行权限、发布资格、全量审计结论或 GitHub 工作流。
