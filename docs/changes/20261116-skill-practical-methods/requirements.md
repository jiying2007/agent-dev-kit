# Skill 实际执行方法修正

## 目标与基线

用户本轮明确允许推送合并，并要求继续全面深度优化所有 Skill。上一轮 11.3.5 已审交付经精确文件树同步成为 PR #270；本轮初始基线为其 HEAD `5b88ec5bce351f68d4756d765e69a4f40bde3f07`，运行资产与原 `63e8f61…` 一致。PR #270 合并后核对主线 tree，再按实际主线记录最终变更基线，不能冒充当前已发布。

本轮选择已证实的执行对象、进程边界和资源测量缺口，改进现有 Skill/示例的实际用法。全量覆盖沿用上轮 65 项清单，本轮对新增方法重新深读，不用改动数量表示质量。

## 验收

1. Review 模板按明确目标取得 staged、working-tree 或已核基线到 HEAD 的真实 patch；同文件 staged/unstaged 并存、clean 已提交分支也不能漏掉目标。记录 overlay，不改 index、不猜 main、不扩展执行权限。
2. 纯 Skill 导出中的 context/handoff 默认可依靠随包正文生成有效交接；源仓 schema/template 仅在核验源码根及文件可读时可用。保留目标、已确认事实、状态/阻塞、scope/permission、raw evidence 与下一动作，不新增资源副本或运行时。
3. ADC 样例在其声明支持的整数宽度上保留错误返回和钳位行为；24 位及 INT_MAX 端点满足独立不变量，乘法中间量不发生有符号溢出。实际 native C 编译/执行进入既有测试入口，不把 host 结果当板端资格。
4. 性能 Skill 按问题区分堆峰值/时间线、错误/泄漏和 RSS；采样/插桩扰动及工具可用性明确，不声称本机运行了缺失的 Valgrind。
5. flaky 排障在 suite/独跑差异或共享状态线索下保留原顺序、seed、worker 和进程边界，比较污染前序与反序并缩小前序集合；新进程独跑全绿不单独证明同进程污染修复，不强制所有偶发问题套矩阵。
6. 有完成时限的协议操作包含阶段、尝试及退避的剩余预算，识别 SDK/调用层叠加重试并明确责任。保留可重试语义、非幂等 UNKNOWN 对账、协议时序和长连接寿命边界，不跨主机传递本地单调钟绝对值。
7. CMake configure/build/test/artifact 绑定同一实际 preset binaryDir 和 configuration；preset 名称可不同，preset/手工配置不混用。保留实际执行后端和空测试失败要求。本机 CMake/Ninja 不可用：本地静态反例不能称真实构建；增加可运行的真实 CMake fixture，并在具备工具的 CI 核验，缺失工具明确记录。
8. 现有版本、预算和安全/发布门禁保持；新版本计划 11.3.6。原型/方法反例、真实源码回归、定性对话与平台发布分别记录，不推断模型 Token/费用或硬件收益。

## 非目标

不引入第三方 Skill 整包、新 runtime、付费/外部模型调用、Codex/ChatGPT Work Cloud/CLI 共享额度、定时巡检或 KWS/audio/safe 工作；不修改真实设备或生产服务，不放宽任何内容、审查或 CI 上限。
