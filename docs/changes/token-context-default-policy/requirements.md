# Requirements

## Goal
Make token/context efficiency a default cross-chain governance rule without creating a duplicate token-lean asset profile or weakening high-risk evidence gates.

## Acceptance
- All profiles/workflows inherit a balanced baseline through the always-loaded repository rule.
- Low Token remains a runtime budget overlay (`fast`), not a manifest product profile.
- High-risk work restores `audit/L3` raw evidence.
- Agent/skill/tool/reference detail is progressively disclosed and deferred until intent match.
- Stable reusable context precedes dynamic context; runtimes track input/output/cached/total token usage when supported.
- Full evidence remains retrievable while active-context summaries stay bounded.
- Existing token budget, strict asset validation and full regression remain green.

## Non-goals
- No product `manifest.json` profile changes.
- No workflow implementation refactor in this change.
- No release identity or runtime boundary change.
