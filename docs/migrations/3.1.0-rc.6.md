# 3.1.0-rc.6 治理合同与远程取证加固迁移

本迁移面向 `3.1.0-rc.5 -> 3.1.0-rc.6`。RC6 封装 RC5 release source 之后进入主线的 MCP 2026 governance-only activation、嵌入式远程 ADB/HIL 取证加固和 G11+ 架构优化模板。

## 行为边界

- MCP active protocol governance contract 为 `2026-07-28`，runtime、Tasks、Apps 和 extensions 仍关闭。
- 远程设备调试默认只读，失联后熔断写操作和无界重试。
- 架构优化报告保留 G1-G10 基线，并允许由 SSOT 管理连续 G11+ 扩展项。
- direct target 仍为 experimental；RC6 不代表 runtime certification、Software M5 certification 或 final `3.1.0`。

## 升级与回退

- 升级前验证 RC5 artifact checksum，并执行 RC5 到 RC6 release rehearsal。
- RC6 candidate rollback 必须恢复 RC5 managed hashes。
- Codex source-to-live 需要独立 owner 授权；未授权时保持 `required-pending-owner-authorization`，不得自动 apply。
