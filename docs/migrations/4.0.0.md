# 4.0.0 Runtime Control 破坏式迁移

本迁移不兼容 3.x 的独立 Token monitor、Execution Guard 或 runtime-specific 决策逻辑。

## 删除

- `agent_dev_kit.token_monitor`、`agent_dev_kit.execution_guard`。
- `devkit.sh token`、`devkit.sh execution`。
- `token_usage_event/v1`、`token_monitor.*`、`long_task_state/v1`、`execution_guard.*`。
- 所有 alias、fallback、dual-read 和 dual-write。

## 唯一入口

Runtime adapter 使用 `agent_dev_kit.runtime_control.reduce_events()` 与 `evaluate()`；用户 CLI 由目标
runtime 提供。唯一合同为 `runtime_control.event/state/decision/v1`。

## State

旧 goal、cooldown、dashboard 和 monitor state 不迁移。切换后从空 Runtime Control Journal 创建新
Goal；旧 state 只允许保留在切换前 backup，不得被 4.0.0 读取。

## Rollback

只允许整包恢复到切换前 source/live backup。禁止把 3.x module、state 或 CLI 局部放回 4.0.0。
