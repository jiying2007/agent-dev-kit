# Hardware Interaction Rules

## 目标

本文件定义硬件交互类任务的默认红线，避免 Agent 在证据不足时给出危险操作建议。

## 红线

- 不建议用户执行可能损坏硬件的操作，除非输入中已明确电气参数、保护措施和回滚方式。
- 不臆造寄存器地址、位域含义、时序、电压、电流或引脚复用；缺少 datasheet/原理图时必须标记为待确认。
- 不把“编译通过”声明为“硬件可用”；硬件可用必须有上板日志、波形、寄存器读回、HIL/SIL 报告或等价证据。
- 对烧录、擦写、熔丝、bootloader、时钟树、电源域、JTAG/SWD 锁定等操作必须提示不可逆或半不可逆风险。
- 调试建议应优先从只读观测开始，再进入低风险复现实验，最后才进入写寄存器、刷固件或改硬件连接。

## 加载方式

该文件由 `embedded_context_layers.L1-always-loaded` 引用，只保存通用硬件红线；板卡专用细节放入项目文档或 `knowledge/L2-domain/`。
