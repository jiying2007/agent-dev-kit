## 4. Approval Checklist (审批清单)

### 前置条件检查
- [ ] 设计文档已完成并评审通过
- [ ] 代码已通过 Code Review (review-report: PASS)
- [ ] 所有测试通过 (test-report: PASS)
- [ ] 覆盖率指标达标
- [ ] 无遗留 Critical/Major 问题
- [ ] 回滚方案已制定并验证

### 变更规范检查
- [ ] 变更范围与设计文档一致
- [ ] 不包含无关的变更（一个变更只解决一个问题）
- [ ] Commit message 格式规范 (<type>(scope): <summary>)
- [ ] 文档已同步更新
- [ ] 变更日志 (CHANGELOG) 已更新

### 部署就绪检查 (发布到 Production 时必填)
- [ ] Staging 环境验证通过
- [ ] 监控告警已配置
- [ ] 回滚步骤已文档化
- [ ] 相关团队已通知 (运维/QA/客服)
- [ ] 发布时间窗口已确认
