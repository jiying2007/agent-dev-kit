## 5. Definition of Done (完成定义)

一个 Story/Task 被视为"完成"，必须满足以下所有条件：

- [ ] 代码已编写并通过本地测试
- [ ] 单元测试覆盖率达标 (≥[N]%)
- [ ] 代码已提交并通过 CI 构建
- [ ] 代码已通过 Code Review (review-report: PASS)
- [ ] 集成测试通过
- [ ] 相关文档已更新（API 文档、README 等）
- [ ] 验收标准全部通过
- [ ] 无遗留的 Critical/Major Bug
- [ ] 部署到 Staging 环境并验证通过 (如适用)
